7. TRANSIÇÃO NAVBAR → PROGRESS PILL
==================================================

IMPORTANTE:

A Navbar não deve simplesmente desaparecer quando o usuário rolar para baixo.

O comportamento deve ser baseado no contexto da página.

Estado 1:

Usuário está no Hero.

Mostrar Navbar completa.

Estado 2:

Usuário saiu do Hero.

Esconder Navbar.

Mostrar Progress Pill.

Estado 3:

Usuário retorna ao Hero.

Esconder Progress Pill.

Mostrar Navbar novamente.

A transição deve ser suave.

Navbar:

opacity 1 → 0
translateY 0 → -15px

Progress Pill:

opacity 0 → 1
translateY -10px → 0
scale .98 → 1

Duração aproximada:

350–450ms

Usar easing suave.
